# 가계부

사기 전에 써도 되는지 알려 주는 통장 쪼개기 가계부예요.

## 무엇을 하나요

통장을 수입 · 고정지출 · 이벤트 · 저수지 · 저축투자로 나눠 두고, 매달 배분과 지출을 기록하면 이런 걸 알려 줘요.

- **오늘 써도 되는 돈**: 생활비 항목마다 남은 돈을 남은 날로 나눠 매일 다시 계산해요.
- **사도 돼?**: 금액과 항목을 고르면 괜찮아요 · 가능하지만 · 비추천 세 단계로 알려 줘요.
- **이벤트통장 12개월 예측**: 경조사 · 여행 · 명절 일정을 넣어 두면 돈이 모자라는 달을 미리 알려 줘요.
- **정산**: 개인 돈으로 낸 지출을 모아 누구에게 얼마를 돌려줄지 보여 줘요.
- **함께 쓰기**: 가계부 하나를 두 사람이 같이 써요. 사람마다 생활비 · 용돈 통장을 둘 수 있어요.

데이터는 내 구글 드라이브의 구글 시트에 저장돼요. 가계부 하나가 스프레드시트 하나예요. 따로 운영하는 서버는 없어요.

- 배포 주소: https://budget-app-mocha-pi.vercel.app

## 체험 모드

구글 로그인 없이 써 볼 수 있어요. 첫 화면에서 **체험해 보기**를 누르면 돼요.

- 예시 가계부 '민지·준호 가계부'가 열려요. 함께 쓰는 월급통장 하나에 민지 월급(21일 3,200,000원) · 준호 월급(25일 2,800,000원) 수입 계획이 있고, 21일에는 생활비(민지) · 생활비(준호) · 이벤트, 25일에는 용돈(민지) · 용돈(준호) · 저축투자로 정한 금액을 보낸 뒤 나머지는 모두 저수지로 가요. 사람마다 생활비 통장(고정비 · 항목 예산)과 용돈 통장이 있고, 홈은 민지 기준 '오늘 내가 써도 되는 돈'으로 열려요. 그 밖에 사람마다 생활비 항목 예산 7개, 일정, 지출, 개인 돈으로 내고 돌려받을 돈(오늘 돌려줄 것 · 다음 월급날에 돌려줄 것 · 이미 돌려준 것), 16회차까지 낸 TV 할부(24개월), 숙소 예약금 · 항공권을 미리 낸 석 달 뒤 제주 여행(예산 900,000원)이 미리 들어 있어요.
- 모든 화면과 기능을 그대로 써 볼 수 있어요. 새 가계부(공용 · 개인)도 만들 수 있어요.
- 데이터는 **이 브라우저에만** 저장돼요. 다른 기기나 다른 사람과는 함께 쓸 수 없어요.
- 브라우저 사이트 데이터를 지우면 체험 가계부도 함께 지워져요. 사생활 보호 창에서는 창을 닫을 때 사라져요.
- 구글 설정을 하지 않은 상태에서는 **구글로 시작하기** 버튼이 꺼지고 체험 모드만 쓸 수 있어요.

## 함께 쓰기 (공유)

공용 가계부는 구글 시트 공유로 함께 써요. 앱은 `drive.file` 권한만 쓰기 때문에, 남이 공유한 시트는 **구글 파일 선택 창에서 한 번 골라야** 읽을 수 있어요.

1. **설정** → **멤버 · 공유**에서 상대의 구글 이메일로 **초대하기**를 눌러요. 시트가 그 이메일로 공유돼요(편집 권한).
2. 같은 화면의 **초대 링크**에서 **링크 복사**를 눌러 상대에게 보내요. 링크는 `https://<주소>/start?open=<스프레드시트 id>` 모양이에요.
3. 상대가 링크를 열면 '가계부에 초대받았어요'가 보이고, 구글로 로그인하면 그 시트만 골라 둔 파일 선택 창이 떠요. **선택**만 누르면 가계부가 열리고 최근 목록에 남아요. 다음부터는 링크 없이 열려요.
   - 이미 읽을 수 있는 시트(내가 만든 시트나 전에 고른 시트)면 선택 창 없이 바로 열려요.
   - 선택 창을 닫으면 **다시 열기**로 다시 띄울 수 있어요.
4. 링크가 없어도 돼요. 구글로 처음 로그인해 최근 가계부가 없으면 시작 화면 맨 위에 **공유받은 가계부가 있나요?**가 보여요. **공유받은 가계부 열기**를 눌러 그 시트를 고르면 돼요.

### 아이폰 홈 화면 앱 · 카카오톡 같은 앱 안에서

- **아이폰 홈 화면에 추가한 앱**에서는 구글 파일 선택 창이 'Google 계정에 액세스할 수 없습니다'로 실패해서 띄우지 않아요. **공유받은 가계부 열기**를 누르면 그 자리에 **초대 링크 붙여넣기** 칸이 열려요. 초대 링크 · 시트 주소 · 시트 id 를 붙여 넣으면(카톡 메시지를 통째로 붙여도 돼요) 바로 열어 봐요. 내가 만든 시트이거나 Safari 에서 한 번 고른 시트면 열려요.
  - 안 열리면 **Safari에서 한 번만 열어 주세요** 안내와 **Safari로 열기** 버튼이 보여요. 누르면 초대 링크를 복사하고('링크를 복사했어요. Safari에 붙여넣어 주세요') Safari 로 넘겨요. Safari 에서 링크를 열고 가계부를 고르면 그다음부터 홈 화면 앱에서도 열려요.
  - 홈 화면 앱에서 초대 링크(`?open=`)를 열어도 같아요: 선택 창 없이 바로 열어 보고, 안 되면 Safari 안내.
- **카카오톡 · 네이버 · 인스타그램 · 페이스북 · 라인 · 다음 · 에브리타임 같은 앱 안 브라우저**에서는 구글 로그인이 막혀요. 로그인 버튼 위에 '카카오톡 같은 앱 안에서는 구글 로그인이 막혀요. Chrome이나 Safari로 열어 주세요'가 보여요(버튼은 그대로 누를 수 있어요).
  - 안드로이드: **Chrome으로 열기**(Chrome 으로 지금 주소를 열어요) · **링크 복사**
  - 아이폰 카카오톡: **Safari로 열기** · **링크 복사** · '오른쪽 아래 ··· → Safari로 열기'. 다른 앱은 **링크 복사**와 메뉴에서 Safari 로 여는 방법
  - 초대 링크로 들어왔으면 먼저 바로 열어 보고, 안 되면 같은 안내와 **그래도 파일 선택 창 열기**가 보여요.
- 안드로이드 Chrome 과 거기서 설치한 앱은 그대로예요.

### 멤버와 이름은 공유 설정에서 저절로

- 가계부의 사람(멤버)은 **구글 시트를 공유받은 사람**이에요. 가계부를 열 때와 **공유 목록 새로고침**을 누를 때 Drive `permissions.list`로 공유 목록을 읽어 시트의 `멤버` 탭에 맞춰요. 구글 시트에서 직접 공유한 사람도 들어와요.
- 이름은 구글에 보이는 그대로예요. 구글 이름이 바뀌면 따라 바뀌어요(비어 있으면 원래 이름을 지켜요). 권한(소유자 · 편집자 · 댓글 작성자 · 보기 전용)도 함께 보여요.
- 공유가 풀린 사람은 행을 지우지 않고 `공유` 칸을 '아니오'로 바꿔요. 사람 고르기에서는 빠지고, 예전 기록에는 이름이 그대로 보여요. 그룹 · 도메인 · 링크 공유가 섞여 있으면 누가 빠졌는지 알 수 없어서 표시하지 않아요.
- 로그인한 나는 언제나 멤버예요(이름 = 구글 프로필 이름). 혼자만 공유돼 있으면 모든 사람 고르기에 나 한 사람만 보여요.
- 바뀐 게 있을 때만 한 번에 써요. **보기 · 댓글 권한**이면 구글이 공유 목록을 보여 주지 않아서(403) 멤버는 그대로 두고 나만 확인해요. 그때는 쓰기도 막혀 화면에만 반영돼요.

체험 모드 가계부는 이 브라우저에만 저장돼서 링크로 공유할 수 없어요. 링크 복사를 누르면 구글 가계부에서만 된다고 알려 줘요. 체험 멤버는 그대로예요.

## 기술 구성

| 항목 | 사용한 것 |
| --- | --- |
| 프레임워크 | Next.js 16 (App Router), React 19, TypeScript (strict) |
| 배포 | Vercel. 화면은 모두 정적 페이지예요. 서버는 로그인용 작은 API(`/api/auth/*`, Vercel 무료 함수) 하나뿐이고 가계부 데이터는 다루지 않아요 |
| 데이터 저장 | 구글 시트 (Sheets API v4 · Drive API v3를 브라우저에서 직접 호출). 체험 모드는 브라우저 저장(localStorage) |
| 로그인 | 구글 인증 코드 흐름 + 갱신 토큰. 갱신 토큰은 암호화한 httpOnly 쿠키에만 두고, 브라우저는 1시간짜리 액세스 토큰만 받아요. 서버 설정이 없으면 예전처럼 Google Identity Services 팝업으로 로그인해요 |
| 공유받은 가계부 열기 | Google Picker (구글 파일 선택 창) |
| 화면 | 웹 공통 디자인 시스템 토큰 + 자체 UI 키트. 글꼴 Pretendard, 선 아이콘(SVG). 움직임은 디자인 시스템 motion.md 기준(CSS 는 components.css, 스크립트가 필요한 숫자 세기·목록 추가/삭제·창 닫힘은 src/ui/motion.ts). '움직임 줄이기' 설정을 따라요 |
| 테스트 | Vitest 3, Testing Library, jsdom |
| 앱 설치 | PWA (홈 화면에 추가). 오프라인 입력은 지원하지 않아요 |

구조는 네 층으로 나뉘어 있어요.

```
화면 (src/app)
  └─ 상태 (src/state)        로그인 · 가계부 선택 · 데이터 · 계산값 · 행동
       ├─ 계산 (src/domain)   항목별 생활비 · 이벤트 예측 · "사도 돼?" 판단 · 청구 정산일 · 이번 달 정산 · 저수지에서 빌린 돈 · 할부 회차 · 여행 예산 · 가져오기 파일 확인 (순수 함수)
       └─ 저장 (src/storage)  구글 시트 / 브라우저 저장 (같은 인터페이스)
            └─ 구글 (src/google)  로그인 · 토큰 · 파일 선택 창
                 └─ 로그인 서버 (src/app/api/auth → src/server/auth)  갱신 토큰 쿠키 · 새 액세스 토큰
```

화면은 상태 층만 불러요. 저장 위치를 바꿔도 화면 코드는 그대로예요.

## 폴더 구조

```
budget-app/
├─ PLAN.md                기획서
├─ README.md
├─ .env.example           구글 환경 변수 견본
├─ public/icons/          앱 아이콘 (192 · 512 · maskable · SVG)
└─ src/
   ├─ app/                화면 (Next.js App Router)
   │  ├─ api/auth/        로그인 서버 (login · callback · token · logout · status). 본체는 src/server/auth
   │  ├─ layout.tsx       글꼴 · 테마 · 알림 · 상태를 감싸는 최상위 틀
   │  ├─ manifest.ts      PWA 설정
   │  ├─ globals.css
   │  ├─ start/           로그인 전 첫 화면 · 가계부 고르기
   │  │  └─ new/          새 가계부 만들기 (시작 잔액 → 매달 배분(사람별 수입통장) → 고정 지출 · 용돈 → 생활비 예산)
   │  └─ (app)/           로그인하고 가계부를 고른 뒤의 화면
   │     ├─ layout.tsx    앱 틀 (메뉴 홈 · 내역 · + 기록 · 이벤트 · 예산, 내 정보 버튼, 가계부 전환, 월말 처리 창)
   │     ├─ page.tsx      홈 (오늘 써도 되는 돈 · 사도 돼? · 돌려받을 돈 · 부족 알림)
   │     ├─ _home/        홈 · 사도 돼? 화면 부품
   │     ├─ _components/  앱 틀 부품 (메뉴 목록, + 기록 시트, 사람 고르기, 가계부 전환, 월말 처리)
   │     ├─ check/        사도 돼?
   │     ├─ history/      내역: 지출(_expenses/) · 이체 · 통장 잔액(_accounts/: 잔액 · 매달 배분 흐름 · 통장 하나 ?tab=accounts&id=)
   │     ├─ budget/       예산: 월급과 배분(수입 계획 · 매달 배분) → 생활비 항목 → 고정비 · 할부 (사람마다)
   │     ├─ plan/         계획: 이벤트 일정 · 이번 달 정산 · 저수지에 갚을 돈 · 12개월 예측 · 부족 대처 · 여행(trips/: 목록 · 여행 하나 ?id=)
   │     └─ settings/     설정: 가계부 · 통장 · 멤버 · 공유(초대 링크) · 카테고리 · 자주 쓰는 지출 · 파일에서 가져오기 · 테마 · 계정
   │                      (sections/ 의 수입 · 배분 · 생활비 · 고정비 · 할부 카드는 예산 화면이 써요)
   ├─ domain/             데이터 타입과 계산 함수 (화면 · 저장과 무관, 단위 테스트 포함)
   ├─ storage/            저장 계층: 시트 백엔드(sheets.ts) · 브라우저 저장 백엔드(local.ts) · 시트 탭 구조(schema.ts)
   ├─ google/             토큰 관리(session.ts) · 로그인 서버 부르기(server.ts) · 팝업 로그인(gis.ts) · 파일 선택 창(picker.ts) · 환경 변수(config.ts)
   ├─ server/auth/        로그인 서버 본체: 쿠키 암호화(crypto.ts) · 구글 토큰 교환(google.ts) · 요청 처리(handlers.ts). 서버에서만 써요
   ├─ state/              화면이 쓰는 상태: 로그인 · 가계부 선택(session.tsx), 초대 링크(invite.ts), 데이터 · 계산값 · 행동(ledger.tsx)
   ├─ theme/              라이트 / 다크 모드
   └─ ui/                 UI 키트: 디자인 토큰(tokens.css) · 부품 스타일(components.css) · 부품 · 아이콘 · 앱 틀(AppShell) · 움직임 도우미(motion.ts)
```

테스트 파일은 대상 파일 옆(`*.test.ts(x)`)이나 `__tests__/` 폴더에 있어요.

## 로컬에서 실행하기

Node.js 22 이상이 필요해요.

```bash
npm ci                         # package-lock.json 그대로 설치
cp .env.example .env.local     # 구글 환경 변수 파일 만들기 (체험 모드만 쓸 거면 비워 둬도 돼요)
npm run dev                    # http://localhost:3000
```

`.env.local`에는 아래 값을 넣어요. 값을 만드는 방법은 [구글 클라우드 설정](docs/구글-설정.md#구글-클라우드-설정)과 [로그인 서버 켜기](docs/구글-설정.md#로그인-서버-켜기-매번-구글-확인-없이)에 있어요.

```bash
NEXT_PUBLIC_GOOGLE_CLIENT_ID=123456789012-abcdefg.apps.googleusercontent.com
NEXT_PUBLIC_GOOGLE_API_KEY=AIza...
NEXT_PUBLIC_GOOGLE_APP_ID=123456789012
# 로그인 서버 (비워 두면 예전처럼 팝업으로 로그인해요)
GOOGLE_CLIENT_SECRET=GOCSPX-...
AUTH_COOKIE_SECRET=openssl rand -base64 32 로 만든 값
```

- `.env.local`을 고친 뒤에는 `npm run dev`를 껐다 다시 켜야 반영돼요.
- `.env.local`은 git에 올라가지 않아요 (`.gitignore`).
- `NEXT_PUBLIC_`으로 시작하는 세 값은 브라우저로 내려가는 공개 값이에요. 보안은 구글 클라우드의 주소 제한과 테스트 사용자 목록이 지켜요.
- `GOOGLE_CLIENT_SECRET`과 `AUTH_COOKIE_SECRET`은 **서버에만 있는 비밀 값**이에요. 앞에 `NEXT_PUBLIC_`을 붙이지 마세요(붙이면 브라우저로 새어 나가요). 채팅 · 이슈 · 커밋에 붙여 넣지 마세요.

## 검증 명령

| 명령 | 하는 일 |
| --- | --- |
| `npm run typecheck` | 타입 검사 (`tsc --noEmit`) |
| `npm run lint` | ESLint |
| `npm test` | 전체 단위 테스트 (`vitest run`) |
| `npx vitest run src/domain/living.test.ts` | 파일 하나만 테스트 |
| `npm run test:watch` | 파일을 고칠 때마다 다시 테스트 |
| `npm run build` | 배포용 빌드 |
| `npm run validate` | 위 typecheck · lint · test · build를 차례로 모두 |
| `npm run e2e` | 화면 흐름 테스트 (Playwright, 체험 모드). 먼저 `npm run build` |

`npm run build` 뒤에 `npm run start`로 배포용 빌드를 로컬에서 띄울 수 있어요.

PR을 올리면 GitHub Actions(`.github/workflows/ci.yml`)가 위 검증과 화면 흐름 테스트를 자동으로 돌려요.

## Vercel 배포 설정

- GitHub 저장소 **Settings** → **General** → **Default branch**를 `main`으로 둬요.
- Vercel 프로젝트 **Settings** → **Git**(새 화면에서는 **Environments** → **Production** → **Branch Tracking**)에서 **Production Branch**를 `main`으로 둬요.
- `main`에 올라가면 Production(https://budget-app-mocha-pi.vercel.app)으로 배포되고, 다른 브랜치와 PR은 Preview로 배포돼요.
- 환경 변수는 Production과 Preview 둘 다에 넣어요. 바꾼 뒤에는 다시 배포해요.
- 이름과 쓰임: `NEXT_PUBLIC_GOOGLE_CLIENT_ID` · `NEXT_PUBLIC_GOOGLE_API_KEY` · `NEXT_PUBLIC_GOOGLE_APP_ID`(공개), `GOOGLE_CLIENT_SECRET` · `AUTH_COOKIE_SECRET`(비밀, Sensitive).
- `/api/auth/*`만 서버 함수로 돌고 나머지 화면은 정적 페이지예요. 무료(Hobby) 요금제로 충분해요.

## 알려진 한계

- 실시간 동기화는 하지 않아요. 다른 사람이 쓴 기록은 앱을 열거나 새로고침할 때 보여요.
- 오프라인에서는 기록할 수 없어요. 앱은 열리고 마지막으로 맞춘 내용을 볼 수 있어요.
- 두 사람이 같은 기록을 거의 동시에 고치면 나중에 저장한 쪽이 멈추고, 최신 내용을 다시 불러와요. 확인한 뒤 다시 고치면 돼요.
- 로그인 서버가 켜져 있으면 액세스 토큰(1시간)은 만료 5분 전에 저절로 새로 받아요. 테스트 중인 앱은 7일마다 다시 로그인해야 해요.
- 로그인 서버가 꺼져 있으면(팝업 로그인) 1시간쯤 뒤 조용히 다시 받지 못할 때 **구글 다시 연결** 버튼을 눌러야 해요.
- 액세스 토큰은 빠르게 다시 열려고 만료(1시간)까지 브라우저 저장소에 둬요. 갱신 토큰은 브라우저 스크립트가 읽을 수 없는 쿠키에만 있어요.
- 일정 완료처럼 여러 탭에 나눠 쓰는 작업은 한 번에 묶이지 않아요. 중간에 실패하면 앱이 저장된 데이터를 다시 읽어 와요.
- 개인 가계부와 공용 가계부의 연결은 개인 가계부를 만들 때만 정할 수 있어요.
