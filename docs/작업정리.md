## 원칙 (사용자 결정)
- **데이터 구조가 바뀌면 앱이 기존 시트 데이터를 자동으로 맞춘다 (가져오기 파일로 다시 넣지 않는다).** 사용자는 실제 구글 시트 가계부에 직접 입력한다. 데이터 모양이나 기존 행의 뜻이 바뀌는 변경은 앱이 열 때 자동으로 고친다: 다시 해도 같은 결과(idempotent), 빈 칸에 안전, 사용자 행은 지우지 않음, 고친 게 있으면 한 번만 알림. JSON 가져오기 파일을 더 만들어 드리지 않는다
- 저수지는 받는 사람이 아니다: "저수지에 줘야 할 돈은 없어 — 거기서 빌리는 거지, 갚아야 할 돈만 있는 거야." 저수지 관련 금액은 '저수지에 갚을 돈' 하나뿐

- 이번 달 정산 카드 정리 (개선안 1 + 3 적용):

  - 정산 화면 /plan/settle (뒤로 → 이벤트): 지급할 수 있는 돈과 셈, 다음 달로 넘어가요(예상 달), 사람별 항목(날짜 · 이름 · 아이콘 · 금액 · 표시), 고른 합 막대 "고른 N건 · ○원", [지급했어요], 넘으면 넘는 금액 + [저수지에서 빌려 지급]
  - 저수지 돈으로 낸 이벤트 청구는 사람 목록 안에 '저수지에서 빌려 지급' 표시. '저수지에 쓸 돈' · '저수지에서 빌려 줄 돈' 같은 저수지를 받는 쪽으로 쓰는 묶음 · 문구 없앰
  - '저수지에 갚을 돈' 카드 분리: "저수지에 갚을 돈 385만 · 이번 달 갚기 제안 10만 [갚았어요]" + 자세히(이미 저수지에서 지급한 이벤트 청구 한 번에 바꾸기 · 저수지에서 쓴 이벤트 지출 바꾸기 · 빌리고 갚은 기록)
  - 기존 시트 데이터는 그대로 맞게 보임 (행의 뜻은 바뀌지 않음, 화면과 문구만 바뀜)
