## 원칙 (사용자 결정)
- **데이터 구조가 바뀌면 앱이 기존 시트 데이터를 자동으로 맞춘다 (가져오기 파일로 다시 넣지 않는다).** 사용자는 실제 구글 시트 가계부에 직접 입력한다. 데이터 모양이나 기존 행의 뜻이 바뀌는 변경은 앱이 열 때 자동으로 고친다: 다시 해도 같은 결과(idempotent), 빈 칸에 안전, 사용자 행은 지우지 않음, 고친 게 있으면 한 번만 알림. JSON 가져오기 파일을 더 만들어 드리지 않는다
- 저수지는 받는 사람이 아니다: "저수지에 줘야 할 돈은 없어 — 거기서 빌리는 거지, 갚아야 할 돈만 있는 거야." 저수지 관련 금액은 '저수지에 갚을 돈' 하나뿐

## 결정된 것 (다음 작업 순서, 2026-11-10 오후)
1. ✅ **완료 — 정산 요약 + 정산 전용 화면(/plan/settle)**: 이벤트 화면에는 한 줄 요약 + [정산하기]. 전용 화면에서 건별 목록 · 전체 선택/해제 · 사람별 선택(일부 = 중간 상태) · 고른 합 막대 · 지급 · 넘는 금액은 저수지에서 빌려 지급. 저수지는 '갚을 돈'만 남기고 별도 한 줄 카드로(“저수지에 줄 돈” 같은 표현 없음). 홈 카드도 /plan/settle 로. PLAN 4-9 · 6 반영. 행의 뜻은 바뀌지 않아 기존 시트 자동 고치기는 필요 없음
2. **이벤트 '해 보기' → 예외 지출 빼기**: 지난 지출 중 예외(일시적) 후보를 보여 주고 빼면 평소 쓰는 돈 · 예상 잔액 다시 계산. 지출에 '예외' 표시 저장(새 칸, 기존 데이터는 앱이 자동으로 맞춤). 앞으로의 일정 빼 보기 기능은 없앰
3. **매년 일정 한 번에 등록**: 설날 · 추석(날짜 자동) · 어버이날 · 양가 부모님 생신 4분(사람마다 양력/음력) · 결혼기념일 · 직접 추가. 매년 반복 일정으로 넣고 평소 쓰는 돈과 겹치지 않게. 기록에서 찾아 주기는 보조로
4. **평소 쓰는 돈과 적립 카드에 '추천 타협안'**: 적립을 늘리면 배분의 '나머지 → 저수지'가 줄어 저수지 빚을 저수지 돈으로 갚는 것과 같으므로, 실제로 남기는 방법은 지출을 줄이는 것.
   - 적립 = 실제로 필요한 만큼(예외 뺀 평소 쓰는 돈 + 등록 일정 평균, 여유분 없음). **지금 적립이 이보다 적으면 그 금액까지 올리라고 분명히 안내**("적립이 실제 필요보다 월 ○원 적어요 → 월 ○원으로 올려야 해요"). 지출 줄이기로 메우는 건 필요 금액을 넘는 부분(저수지 빚 갚기)만
   - 저수지 빚 = 기본 24개월 분할(12 · 18 · 24 · 36개월로 바꿔 보기), 갚는 돈은 지출을 줄여서 마련 → 카테고리별로 줄일 금액 제시(평소보다 많이 쓰는 카테고리부터)
   - 표시 예: "추천: 적립 월 55만(+5만) · 쓰는 돈 월 16만 줄이기 → 12개월 부족 없음 · 저수지 빚 385만을 24개월에 다 갚아요". 자동 변경 버튼 없음
5. **아이폰 홈 화면 앱 · 앱 안 브라우저**: 아이폰 홈 화면 앱은 초대 링크 붙여넣기로 바로 열기 + "Safari에서 한 번만 열어 주세요" + [Safari로 열기]. 카톡 등 앱 안 브라우저(아이폰 · 안드로이드)는 "Chrome/Safari로 열어 주세요". 안드로이드 Chrome은 그대로
6. **생활비 항목 금액**: 이번 달부터만 반영(지난달 그대로) + 특정 달만 다른 예산
7. **카테고리 정리**: 기록 창은 자주 쓴 6개 + 통장에 맞는 묶음만 + [더 보기] / 합치기(지난 지출 · 예산 · 자주 쓰는 지출 옮김) / 3개월 안 쓴 것 숨기기(되돌릴 수 있음). 삭제 · '간식·편의점' 기본 추가는 안 함
8. **홈 '이번 달 쓴 돈'에 고정비 한 줄**: "고정비 150만 / 210만 · 남은 결제 3건"
8-1. **배분은 누르지 않아도 자동 반영**: '다음 배분에 필요한 금액' 카드와 [배분 금액 맞추기] 버튼은 없앰. 생활비 · 용돈 통장으로 가는 매달 배분은 **기본이 '알아서 맞추기'**(고정비 · 세부 항목 · 할부 · 생활비 예산이 바뀌면 다음 배분 금액이 저절로 바뀜). 기존 시트의 생활비 · 용돈 '정한 금액' 배분은 앱이 자동으로 '알아서 맞추기'로 바꿈(한 번 안내). 매달 배분 목록의 그 줄에 금액만 바로 보여 줌: "21일 · 월급통장 → 민구 생활비 · 128.8만 (자동)", 바뀌었으면 옆에 작게 "지난달보다 +1.5만 · 넷플릭스 시작". 이벤트 · 저축 등은 '매달 같은 금액', 저수지는 '남는 돈 전부'. 방식 이름: 매달 같은 금액 / 알아서 맞추기 / 남는 돈 전부
8-2. **고정비 · 용돈 탭 합치기**: 예산의 '용돈' 탭(개인 가계부로 보내는 용돈, 받는 사람 이메일 필요)은 없애고 고정비 하나로. 용돈 자체는 매달 배분("25일 · 월급통장 → 민구 용돈")으로만 관리. 용돈 통장에서 나가는 십일조 · 헌금 · 개인 지출은 **공용 가계부에서** 고정비/지출로 관리(통장만 '민구 용돈'). 목록은 사람별 탭(민구 / 기쁜 / 함께)과 통장 이름으로 구분, 카테고리로 따로 나누지 않음. 이미 용돈 탭에 직접 등록한 항목은 앱이 자동으로 배분(사람에게 주는 용돈) 또는 고정비로 옮기고 한 번 안내. 개인 가계부 연동은 쓰지 않음(필요하면 나중에 배분 → 개인 가계부 수입으로 연결)
8-3. **예산 화면 시각화(배분 · 고정비)**: 위쪽에 월급날별 돈 흐름 그림(월급통장 → 각 통장, 막대 굵기 = 금액, 21일 · 25일 각각, 자동/남는 돈 표시). 아래는 통장마다 카드 하나: 들어오는 돈(배분 · 날짜) ↔ 나가는 돈(고정비 · 할부 · 생활비 예산 합계와 접힌 상세). 사람별 탭과 함께 사용. 고정비 · 생활비 · 할부 편집은 각 카드 안에서
